# Tutorial screenshots

Drop your app screenshots here as PNG (or JPG — then rename to `.png`). They load automatically into the phone frames on the tutorial page. Each should be a portrait phone screenshot (roughly 9:19).

Expected filenames:

| File | Shows |
|------|-------|
| `signup.png`      | The login / sign-up screen (heading "Create your account") |
| `farms.png`       | The "My Farms" screen |
| `add-field.png`   | The "Add New Field" sheet / map corner selection |
| `create-alert.png`| Admin's "Create alert" sheet |
| `alerts-list.png` | The farmer's Alerts list with alert cards |

If a file is missing, the page shows a labelled placeholder in its place — nothing breaks.
